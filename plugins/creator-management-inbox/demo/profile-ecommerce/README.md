# Demo profile: Quillmoss (fictional)

Used when `provider: demo` and `demo_profile: ecommerce` are set in your settings.
Quillmoss is an invented clean-skincare brand selling on Shopify; Imogen Marsh, every
creator, agency, address, invoice and number here is made up, and every domain ends
in `.example`. Your own profile lives in `~/.claude/inbox/profile/` and is never
mixed with this one. The other demo (`demo_profile: saas`) is Fernwell, an app.
