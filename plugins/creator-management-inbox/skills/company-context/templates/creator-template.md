# Example Creator

> One file per creator you work with, in `~/.claude/inbox/creators/`. Copy this file,
> rename it to the creator's handle (e.g. `mayacodes.md`) and fill in what you know.
> The workflow looks creators up here by name, handle, email or promo code, so it
> can price, renew and personalise from real history instead of guessing.
> Claude keeps these up to date for you if you ask ("add Maya to my creator notes").
>
> `status` drives renewals: `test` (first deal running), `continue` (profitable,
> re-book), `re-onboard` (profitable but gone quiet), `watch`, `cut` (rate no longer
> works, recalibrate), `do-not-re-onboard`.
