# rate-engine reference data

Two data files sit in this directory. Only one of them is ever committed.

## `benchmarks.json` - committed, ships empty

Cohort CPM bands and value rates. This is the file the engine prices off.

It ships as an empty skeleton with the schema documented inline under `_schema`.
Rate bands are derived from one company's conversion economics and are
commercially confidential to that company, so nothing is seeded here. **While it
is empty the engine runs in advisory mode and refuses to print a rate card.**

Regenerate it:

```bash
# 1. run each query in refresh_queries.sql, save rows as JSON into <workdir>:
#    cohorts.json  geo_cells.json  drift.json  backtest.json  snapshot_all.json
python3 ../scripts/assemble_benchmarks.py <workdir> --date YYYY-MM-DD
mkdir -p ~/.claude/inbox/rates && cp <workdir>/benchmarks.json <workdir>/creators_snapshot.json ~/.claude/inbox/rates/
```

Before the first run, fill the CONFIG block at the top of
`assemble_benchmarks.py`: the policy floors and the `value_basis` sentence come
from your profile (`rates.md`, `deals.md`, `data-sources.md`), and nothing else in the pipeline can derive them for you.

## `creators_snapshot.json` - NOT in this repo, and never should be

Per-creator history: name, handle, fees paid, realized value, CAC, ROI, leak
flags and the price book. It is generated by the same assembler run, it is
`.gitignore`d, and it must never be committed, emailed or pasted into a chat.
Treat it the way you would treat a payroll export, because that is roughly what
it is.

The engine reads it from this directory at runtime **if present** and degrades
cleanly if it is not: you lose the own-history override, the price book, the
leak flags and bulk mode, but every cohort-priced card still computes. Bulk mode
exits with an explanation rather than producing an empty CSV.

If you inherited this skill from somewhere and a `creators_snapshot.json` is
sitting here, it is not yours. Delete it.

## How advanced mode prices

Expected value per post = median organic views x the
cohort's current-regime value rate (shrunk toward decay-weighted history, so it
responds to regime changes without overreacting to thin data) x geo multiplier; a
creator with 4+ clean tracked posts is priced on their own realized value instead.
OPEN / TARGET / MAX = 0.4 / 0.5 / 0.8-1.0 x EV, bounded by the market band of what
you actually paid in that cohort.
